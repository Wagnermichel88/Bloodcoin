Oracle reports

Every number we report, open to check.

Each week our server reads US death counts from the CDC, signs them and sends them to the BCUS contract. The contract uses them to set how many new BCUS are created. Below is every report with the exact CDC weeks it used, and a button that checks it against the CDC directly from your browser, without trusting our server.

Who runs this oracle, and why that matters

The oracle is run by the Bloodcoin founder, who also holds a large amount of BCUS. That is a conflict of interest: whoever reports the numbers controls the emission.

The contract only rejects absurd values. A small, plausible-looking change would be accepted. The only protection is that every report is public and anyone can compare it with the CDC. If a report does not match, please say so publicly.

How the number is calculated

Deaths is the sum of US deaths in the 4 weeks up to the report week. 3-year average is the same 4 calendar weeks in each of the previous 3 years, averaged. Only weeks at least 8 weeks old are used, because CDC counts are incomplete before that.

Within ±3 % the target factor is 1.0. Beyond that, each further percent of excess deaths lowers it by 0.05 down to 0.5. Fewer deaths than usual never raise it above 1.0. The factor used for emission moves at most 0.05 per report toward the target.

Source: CDC dataset r8kw-7aab (Provisional COVID-19 Death Counts by Week, total deaths, United States). The CDC still revises recent weeks, usually upward by 1–2 %, so a small difference to today's numbers is normal.

To check from the command line, download a report and the script that creates it (Python 3, no other dependencies for checking), then run:

python3 report.py verify 2026-08-15.json
